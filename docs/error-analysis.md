# Error analysis: what the best configuration leaks

Generated by `scripts/error_taxonomy.py` from `results/m7/error_taxonomy.json`. Configuration `crf+regex+presidio` with typed masking: a gold span leaks when no detected span covers it (a type-agnostic false negative of the stored run). Categories are assigned automatically by `privgate.bench.taxonomy`; each dimension partitions the leaked spans (counts sum to the total). Examples: [error-examples.md](error-examples.md).

Definitions. **Format**: first matching rule of *all digits* (every non-space character is a digit), *contains punctuation* (any non-alphanumeric, non-space character), *mixed alphanumeric*, *title-case word(s)*, *lowercase word(s)*, *other letters*. **Position**: *table / delimited line* (the line has two or more `|` or a tab), *key: value line* (the line starts with a short label followed by `:` or `=` and the span lies after it), otherwise *prose*. **Untargeted**: the raw label is targeted by none of the five M3 detectors (privgate.bench.support).
